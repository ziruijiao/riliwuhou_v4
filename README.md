# 日历午后 riliwuhou_v4
> 一款轻便好用的小工具，支持本地检索、云端AI能力


## 📖 项目介绍
日历午后（riliwuhou_v4），由焦梓睿与 Lin-zikang 联合开发并开源。
本项目内置敏感词词库，提供**本地检索**与**云端AI**两种能力，轻量化设计，开箱即用，部署简单。

仓库地址：https://github.com/ziruijiao/riliwuhou_v4/tree/main/Sensitive-lexicon-main

## ✨ 功能特性
- ✅ 本地敏感词检索，无需依赖网络，速度快
- ✅ 对接云端AI，拓展识别、处理能力
- ✅ 轻量架构，资源占用低
- ✅ 开源免费，MIT协议，可自由二次开发
- 
## 🚀 快速使用
1. Clone 本仓库
```bash
git clone https://github.com/ziruijiao/riliwuhou_v4.git
```

2. 进入项目目录

```bash
cd riliwuhou_v4/Sensitive-lexicon-main
```
3. 根据项目说明启动程序，配置本地检索或云端 AI 参数

> 
> 提示：云端 AI 功能需要自行配置对应的接口密钥，词库可按需增删修改。
